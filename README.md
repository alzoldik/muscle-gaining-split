# دليل التضخيم المتكامل — جدول تماريني الشخصي للجيم 🏋️‍♂️

> **عن المشروع:** عملت التطبيق ده لنفسي عشان الجيم وتماريني اليومية — يجمع جدولي المعدّل للأسبوع كامل (٧ أيام)، صور وفيديوهات الأداء الصحيح عالية الدقة لكل تمرين، روابط شرح يوتيوب، ومؤقتات الراحة والإطالات في مكان واحد سريع وسهل الاستخدام على الموبايل وأنا في الجيم.
>
> **تم البناء والتطوير باستخدام:** **Google AI Studio (Gemini)** 🤖✨

---

## المميزات الأساسية

- **جدول الـ ٧ أيام المعدّل للتضخيم (٥ أيام تدريب + يومين راحة):**
  - يوم ١: ضهر وكتف (سحب) — مع إضافة الكتف الخلفي وتعديل ترتيب `T-bar row` قبل `Kelso shrugs`.
  - يوم ٢: صدر ودراعات — مع رفع حجم الصدر الأسبوعي وإضافة `Dips / Close grip bench`.
  - يوم ٣: رجل (هامسترنج وجلوتس) — مع رفع `Smith hip thrust` لـ ٣ مجموعات وإضافة `Abductor machine`.
  - يوم ٤: راحة واستشفاء (`10 min Mobility`).
  - يوم ٥: جزء علوي (`Upper`) — استبدال ضغط الكتف بالدمبل لحماية المفصل وإضافة `Face pull`.
  - يوم ٦: رجل (كوادز) — البدء بـ `Hack squat` ثم `RDL` بـ `RIR 2-3` مع إضافة `Back extension 45°` و`Tibialis raise`.
  - يوم ٧: راحة أو مشي خفيف ٣٠ دقيقة + مرونة.
- **عروض حركة عالية الدقة (`960×540 HD`) لكل تمرين وإطالة:**
  - حلقات حركية جاهزة عالية الوضوح مع إمكانية الإيقاف/التشغيل، السرعة البطيئة (`0.5x`) لمراجعة التكنيك، وزر **تكبير HD**.
  - رابط بحث يوتيوب مباشر لكل تمرين ولكل حركة إحماء وإطالة.
- **متابعة التمرين أثناء الجيم:**
  - مربعات تحديد المجموعات المكتملة لكل تمرين (تُحفظ تلقائيًا في `localStorage`).
  - مؤقت راحة وإطالات مدمج مع أزرار `+15ث / -15ث`.
  - وضع نهاري وداكن (`Dark / Light Mode`).
- **التحليل العلمي والوقاية من الإصابات:**
  - قسم **مميزات الجدول** و**العيوب التي تم تصحيحها**.
  - قسم **تمارين الحمل الزائد (٧ تمارين)** والمشاكل المحتملة والحل التشريحي الآمن لكل تمرين.
  - بروتوكول **الإحماء المتحرك قبل التمرين** و**الإطالات الثابتة بعد التمرين** بمؤقت ٣٠ ثانية.
  - **حاسبة التغذية الشخصية** (سعرات، بروتين، كرياتين، ماء) وأداة تعديل التمارين حسب الإصابات (الركبة / أسفل الضهر / الكتف).

## التقنيات المستخدمة

- **React 19** + **TypeScript**
- **Vite 8**
- **Tailwind CSS v4** (تصميم عربي متكامل `RTL`)
- **Lucide React** للأيقونات

---

## التشغيل محليًا (Local Development)

1. تثبيت الحزم:
   ```bash
   npm install
   ```

2. تشغيل السيرفر المحلي على بورت `3000`:
   ```bash
   npm run dev
   ```

3. بناء نسخة الإنتاج:
   ```bash
   npm run build
   ```

4. فحص الأنواع (`TypeScript`):
   ```bash
   npm run lint
   ```
